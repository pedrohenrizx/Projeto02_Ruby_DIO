# Projeto 02 - Ruby | DIO

Repositório desenvolvido como parte do bootcamp de Ruby na plataforma [Digital Innovation One (DIO)](https://www.dio.me/). O objetivo deste projeto é consolidar conceitos fundamentais da linguagem Ruby através da implementação de um script prático.

---

## 📌 Visão Geral

Este projeto contém a solução prática do segundo desafio proposto no módulo de Ruby, estruturado no arquivo principal `Projeto.rb`. 

> **Dica:** Caso seu desafio específico seja de **Coleções/Arrays** (ex: cálculo de potências com `.map`), **Validação com Gems** (ex: `cpf_cnpj`) ou **Estruturas de Controle**, você pode detalhar a regra de negócio na seção abaixo.

### 🎯 Funcionalidades

- [x] Entrada e processamento de dados via terminal.
- [x] Manipulação de estruturas e tipos nativos de Ruby.
- [x] Apresentação formatada dos resultados para o usuário.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Ruby](https://www.ruby-lang.org/) (versão 3.0+ recomendada)
- **Gerenciador de Dependências (se aplicável):** Bundler / RubyGems

---

## 🚀 Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter o Ruby instalado em sua máquina. Para verificar, execute no terminal:

```bash
ruby -v
```

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/Projeto02_Ruby_DIO.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd Projeto02_Ruby_DIO
   ```

3. **Instale dependências (se o projeto utilizar Gems externas):**
   ```bash
   bundle install
   ```

4. **Execute o script:**
   ```bash
   ruby Projeto.rb
   ```
